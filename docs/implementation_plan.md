# Implementation Plan - Vibe Coding Focus Cockpit

We will build a single-page, premium developer-centric dashboard called **Focus Cockpit** using Vite, React, TypeScript, and Tailwind CSS. The dashboard will track developer missions, active AI agent tasks, waiting states, a task stack, developer resume notes, and quality gates, all with interactive mock states and live simulated micro-actions.

## Design & Theme Details
- **Aesthetic:** High-end developer console / cockpit theme (dark mode first).
- **Harmonious Palette:** 
  - Slate/Zinc dark backgrounds (`bg-zinc-950`, `bg-zinc-900`) for depth.
  - Glowing translucent overlays (glassmorphism: `bg-zinc-900/60 backdrop-blur-md`).
  - Dual modes:
    - **Execution Mode:** Electric indigo (`indigo-500`), cyan (`cyan-400`), and emerald (`emerald-500`) glow effects.
    - **Waiting Mode:** Warm amber (`amber-500`) and orange (`orange-500`) glow effects, signaling that the user's attention is needed.
- **Typography:** Sleek monospaced and sans-serif fonts (e.g., system font stacks with JetBrains Mono / Inter styling).
- **Interactivity:** Glowing buttons, micro-scale animations, dynamic layout sizing, drag-free state-button task moves, edit modals, and a pulsing simulator simulating AI thoughts and logs.

### 2. Dashboard Components (Source Code)

#### [NEW] [src/App.tsx](file:///e:/playground/vibecoding%20buddy/src/App.tsx)
The central component containing the main cockpit state, layout, and control hub:
- **Cockpit Mode State:** Toggleable `waitingMode` (boolean) which switches theme color accents between electric indigo/cyan (active execution) and glowing amber/orange (waiting mode).
- **Mission State:** `mission` object (`{ title, objective, progress, currentStep, timeElapsed }`) with inline editing.
- **AI Task Simulation:** A `useEffect` loop that runs every 3-5 seconds, simulating AI actions (e.g. `Grep searching...`, `Analyzing dependencies...`, `Writing layout.css...`, `Executing tests...`) and populates a scrolling simulated terminal log.
- **Task Stack State:** An array of task items:
  ```typescript
  interface Task {
    id: string;
    title: string;
    description: string;
    status: 'active' | 'waiting' | 'later';
    priority: 'low' | 'medium' | 'high';
    category: string;
    createdAt: string;
  }
  ```
  - Direct actions to add new tasks, edit existing ones, delete tasks, and transition tasks between columns (`Active`, `Waiting`, `Later`).
- **Resume Note State:** Text value for the developer’s handoff note, editable with raw Markdown text editor and a rendered HTML-like preview.
- **Quality Gate State:** An array of checklist rules (e.g., "Build Succeeds", "Lint Checks Pass", "Aesthetics Verified", "No Console Errors"). The cockpit displays a warning shield when any item is unchecked, and a glowing green "System Cleared" seal when all pass.

## Verification Plan

### Automated Verification
1. **Dependency Check:** Run `pnpm install` and ensure it finishes without version conflicts.
2. **TypeScript Compilation Check:** Run `pnpm tsc --noEmit` to verify type safety.
3. **Production Build Check:** Run `pnpm build` to confirm there are no bundler or module-import path errors.

### Manual Verification
1. **Interactive State Verification:**
   - Click "Toggle Waiting Mode" in the header and verify that the global accents shift from neon purple/indigo to glowing amber/orange.
   - Click "Edit Mission" in the Mission Card, change values, and check if the progress bar updates.
   - Add a new task in the Task Stack, change its column via move controls, and verify its priority color tags.
   - Edit the Developer Resume Note and toggle between write and view panels.
   - Click on the Quality Gate checkboxes and watch the status shift between "BLOCKED" and "SECURED".
